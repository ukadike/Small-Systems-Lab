# 05 — Methodology

## Research design

Small Systems Lab uses a mixed-methods, practice-based research design.

The lab studies learning, making, accessibility, and public-interest technology through:

- studio observation
- project documentation
- artifact analysis
- reflective writing
- accessibility review
- interviews
- surveys
- public showcases
- partner feedback
- GitHub activity analysis

## Methodological commitments

### Practice-based research

Student prototypes are treated as research artifacts. The process of building, testing, documenting, and revising is part of the knowledge production.

### Participatory design

Where projects involve specific communities, those communities should help define problems, constraints, and measures of success.

### Accessibility review

Every project should include an accessibility review covering keyboard access, screen reader access, multimodal communication, cognitive accessibility, language access, physical access, and known barriers.

### Reflective practice

Students document not only what they built, but what changed in their thinking.

### Open documentation

GitHub repositories serve as public research notebooks, not merely code storage.

## Data sources

Potential data sources include:

- project repositories
- student reflections
- pre/post course surveys
- accessibility review forms
- interviews
- instructor notes
- partner feedback
- prototype demonstrations
- code commits
- showcase materials

## Analysis methods

Potential analysis methods include:

- thematic analysis of reflections and interviews
- rubric-based project assessment
- accessibility checklist scoring
- documentation quality review
- comparative analysis of project iterations
- case study analysis
- network mapping of cross-program collaboration

## Validity and trustworthiness

The lab strengthens research trustworthiness through:

- transparent documentation
- triangulation across data sources
- member checking with partners where appropriate
- clear distinction between observation and interpretation
- explicit limitations
- ethical review before human subjects research

## Limitations

Small Systems Lab should not overclaim impact from early pilots. Initial findings should be framed as exploratory, formative, and context-specific.
