# Syllabus — Small Systems Studio

## Course description

Small Systems Studio introduces accessibility-first creative technology through Arduino, physical computing, creative coding, public-interest design, and documentation.

## Weekly schedule

1. What is a small system?
2. Observation before invention
3. Arduino foundations
4. Sensors and bodies
5. Accessible interaction
6. Data as public material
7. Sonification and tactile output
8. Civic systems and journalism
9. Community context
10. Prototype sprint
11. Accessibility review
12. Documentation workshop
13. Public presentation rehearsal
14. Showcase

## Final project

Build an accessible public-interest prototype with GitHub documentation.
