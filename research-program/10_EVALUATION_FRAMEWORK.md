# 10 — Evaluation Framework

## Evaluation purpose

Small Systems Lab evaluates both student learning and public-interest impact.

## Student learning outcomes

Students should demonstrate:

- systems thinking
- technical prototyping ability
- accessibility practice
- documentation skill
- ethical reasoning
- public communication
- collaboration
- reflection

## Project evaluation rubric

### Technical implementation

- prototype functions
- code is documented
- setup instructions are clear
- hardware choices are explained

### Accessibility

- keyboard access considered
- screen reader access considered
- captions/transcripts included where relevant
- alt text included
- multimodal alternatives considered
- cognitive accessibility considered
- known barriers acknowledged

### Research quality

- problem is clearly defined
- affected users or communities are identified
- context is researched
- limitations are explicit
- next questions are documented

### Public value

- project has a plausible user or community
- public explanation is clear
- risks are acknowledged
- maintenance is considered

## Evidence sources

- GitHub repository
- prototype demo
- student reflection
- accessibility review
- partner feedback
- instructor rubric
- showcase presentation
