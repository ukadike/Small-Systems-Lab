# 16 — Reproducibility Plan

## Goal

Small Systems Lab projects should be reusable, inspectable, and teachable.

## Every technical project should include

- README
- hardware list
- wiring diagram or pin table
- software dependencies
- installation steps
- sample data
- accessibility review
- known limitations
- license
- contributor credits

## Every curriculum project should include

- lesson goals
- audience
- time required
- materials
- accessibility considerations
- facilitation notes
- assessment option
- extension activity

## Every research project should include

- research question
- methods
- data types
- ethics note
- limitations
- future work
