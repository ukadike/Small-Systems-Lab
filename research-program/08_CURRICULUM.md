# 08 — Curriculum

## Course sequence

1. Small Systems Studio
2. Responsible AI and Civic Systems
3. Earth Sensors Lab
4. Accessible by Design
5. Physical Computing Studio
6. Speculative Systems Research

## Course design principles

- accessibility from the first week
- Arduino and physical computing as foundation
- GitHub documentation as scholarly practice
- public-interest prototype as final output
- reflection as evidence of learning
- community context before technical solution

## Capstone requirements

Every final project includes:

- working prototype
- accessibility review
- GitHub documentation
- public-facing explanation
- maintenance notes
- ethical reflection
- schema card
