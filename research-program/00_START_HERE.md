# 00 — Start Here

## What this section is

`research-program/` is the founding PhD-level research architecture for Small Systems Lab,
housed inside the main [Small Systems Lab hub repository](../README.md). The public-facing
pages built from this material live at [`../research/`](../research/index.html).

It is meant to help a university reviewer, faculty mentor, funder, or collaborator understand that the lab is not a vague idea. It has:

- a theory of change
- research questions
- methods
- student learning model
- accessibility commitments
- technical infrastructure
- evaluation plans
- code starters
- schemas
- public website scaffold
