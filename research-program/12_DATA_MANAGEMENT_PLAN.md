# 12 — Data Management Plan

## Data types

Small Systems Lab may produce:

- code
- schematics
- sensor data
- interview notes
- survey results
- accessibility reviews
- student reflections
- photographs
- video/audio documentation
- public project descriptions
- partner feedback

## Data principles

- collect the minimum necessary data
- separate public documentation from private research data
- avoid publishing sensitive access needs without consent
- use clear licenses
- document provenance
- preserve participant dignity

## Public data

Public data may include:

- code
- documentation
- de-identified sensor data
- project cards
- diagrams
- curricula
- templates

## Restricted data

Restricted data may include:

- interview recordings
- raw student reflections
- identifiable accessibility needs
- partner-specific sensitive information
- unpublished research notes

## Storage

Recommended structure:

- `data/public/`
- `data/restricted/`
- `data/README.md`
- `data/metadata.json`

Restricted data should not be committed to public GitHub repositories.

## Reproducibility

Each project should include:

- README
- hardware list
- software dependencies
- setup instructions
- sample data
- known limitations
- accessibility notes
